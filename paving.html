2. Property mapping (auto-detected — open only if a table looks wrong)

Each field is read from the first listed property an object actually has. "(auto)" uses the detected order shown in the dropdown. Changing a mapping re-aggregates without re-reading the model.

Classification keywords (matched against type, family, name, materials, comments, layer)

Comma-separated words; first matching category wins in this order: curb, sidewalk, slab, asphalt, other paving. Floors with an asphalt material default to Asphalt, with a concrete material to Slab; in-place pieces without any Revit quantity default to Curb. Use the Types tab to override one type.

3. Results

Click any row to select those objects in the viewer. Areas come from the model's Area property (Revit floors, IFC base quantities) and are plan areas; thickness from the floor type; concrete CY and asphalt tons use the pay thickness in the Types tab (defaults to the model thickness). Rows marked bbox are estimated from bounding boxes because the element carries no quantity (in-place families).
