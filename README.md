## Important: these files must be reachable by HTTPS

Trimble Connect loads extensions from a **public HTTPS URL** â€” it fetches `manifest.json` from its servers (so the URL must be CORS-enabled) and loads `index.html` in an iframe in the browser. A network drive path like `Y:\...` cannot be used directly.

Easy hosting options (all three files go up together, keep them in one folder):

1. **GitHub Pages** (free, simplest): make a repo, drop the 3 files in, enable Pages. GitHub Pages sends `Access-Control-Allow-Origin: *`, so the manifest fetch works out of the box.
2. **Netlify Drop** (free, no account tooling needed): drag the folder onto https://app.netlify.com/drop.
3. **Company web server**: any IIS/nginx that serves this folder over HTTPS. Make sure `manifest.json` is served with the header `Access-Control-Allow-Origin: *`.

After hosting, **edit `manifest.json`** and replace `https://YOUR-PUBLIC-HOST/trimble-connect/index.html` with the real URL of `index.html`, then re-upload it.

## What Point Extractor does

- Asks Connect for the signed-in user's access token (one-time consent prompt â€” no separate login).
- Reads every saved **View** in the current project via `GET /tc/api/2.0/views?projectId=â€¦` and `GET /tc/api/2.0/views/{id}`.
- Collects markups with `type === "measure"` (single-point measurements). Connect stores these in **millimeters**; the tool converts to US survey feet (mm Ã· 304.800609601), international feet, or meters.

## Completion (3D Viewer tool) — proposed model vs as-built model, percent complete

1. Load the design model and the as-built model in the 3D Viewer, open **Plateau Tools** (left toolbar) → **Completion**.
2. The two pickers guess which model is which (a name with `-AB` / `AS-BUILT` / `ASBUILT` / `RECORD` is taken as the as-built). Fix them if needed, set the location tolerance (default 3 ft) and the length share at which a pipe counts as complete (default 95 %), then **Compare**.
3. Tiles: **Overall completion** (average over every proposed object in scope; pipes pro-rated by installed length), **Pipe installed by length**, **Structures / other** complete, **Model-to-model** (the whole as-built model as a share of the proposed model, by object count and by LF, no matching).
4. Tabs: by category (object type + layer), by pipe size, every proposed item (status, matched as-built object, installed LF; click a row to select the objects in the viewer, tick *Zoom on click* to fly to them), and as-built objects with no proposed counterpart. Untick categories to leave e.g. water DIP or fittings out of the percentage.
5. **Copy for Excel** (summary), **CSV** (items + as-built only), **HTML report** (self-contained page).

Matching: by name first (trimmed, case-insensitive, same kind: pipe vs structure), then by location — an as-built pipe whose two ends both lie within the tolerance of a proposed pipe run, a structure within the tolerance of a proposed structure. Several as-built pieces can add up to one proposed run. Lengths and coordinates come from the Civil 3D properties (`Geometry:3D Length`, `Pipe Start/End Easting/Northing`, `Structure Easting/Northing`; LengthMeasure values are mm and converted, bare numbers are model feet); objects without Civil 3D coordinates (3D solids) use their bounding-box centre. Known difference from the desktop exe: Connect reports the AutoCAD `General · Layer` (`0`) for 3D solids, the exe reports the TrimBIM instance layer.
